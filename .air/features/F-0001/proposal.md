# Feature proposal: answer questions from prepared documents

## Proposal

Sophista answers a user's question using relevant content from prepared
Markdown documents and returns source information the user can verify. If no
relevant source is found, the language model may answer from its general
knowledge, provided the result clearly identifies that it is not based on
found organizational knowledge.

## Evidence

The project owner described this as the first desired user outcome and said
acceptance requires an answer with a verifiable source citation. The owner also
confirmed that general model knowledge may be used when no relevant source is
found if this is clearly disclosed.

Source: owner responses in the task conversation on 2026-11-05.
